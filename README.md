# 📊 Statistical Business Analysis

## 📌 Project Overview

This project performs a complete statistical analysis on business sales and customer datasets using Python. The analysis includes descriptive statistics, data distribution analysis, correlation analysis, hypothesis testing, confidence intervals, and regression analysis.

The main goal of this project is to identify meaningful business insights and support data-driven decision-making.

---

# 🎯 Objectives

- Calculate descriptive statistics
- Analyze data distributions
- Perform correlation analysis
- Conduct hypothesis testing
- Calculate confidence intervals
- Perform regression analysis
- Generate business recommendations
